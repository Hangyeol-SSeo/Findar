# 자유양식 지원서 기준 양식

`freeform-application.docx`는 사용자가 승인한 3쪽 프로토타입 원본입니다.
이력서·경력 및 경험 상세·자기소개서의 글꼴, 표, 문단 스타일, 여백, 머리글과 바닥글을 제공합니다.

- SHA-256: `d2b2205a9b4ce2c1e0e9a4a39678a0c24e04da7c4b3400e5281d4032dace498a`
- 생성기: `scripts/generate-application-docx.py`
- 원본에는 실제 개인정보나 경력이 없습니다.
- 생성 시 표의 행과 문단을 복제하고 내용을 입력합니다. 글꼴·테마·스타일 등 나머지 패키지 구성은 그대로 보존합니다.
- 템플릿을 수정할 때는 생성기의 슬롯 위치와 문서 보존 테스트를 함께 수정하고, 빈 양식과 실제 데이터가 입력된 결과를 모두 렌더링해 확인합니다.
