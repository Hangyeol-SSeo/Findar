# 금융권 자유양식 입사지원서 템플릿

KCGI자산운용의 첫 페이지 정보 구조와 DS투자증권의 지원 부서·지원 구분 표시를 참고해 제작한 Findar 공통 양식입니다. 회사 로고나 회사 전용 심사 항목을 포함하지 않으며, 실제 개인정보나 경력도 없습니다.

## 페이지와 정보 구조

- A4 세로, 상하 17mm·좌우 18mm 여백. Nanum Gothic 본문 10.5pt, 서술형 자기소개서 11pt. 본문·제목은 검정이며 표 레이블과 헤더에는 연한 회색을 씁니다.
- 첫 페이지는 중앙 제목 다음에 지원 회사·지원 부서·지원 구분 표를 배치합니다. 이름·연락처·이메일은 별도 인적사항 표에 넣습니다. 생년월일·성별·국적·주소는 사용자가 포함을 선택한 경우에만 넣습니다.
- 학력·경력·자격 및 어학을 같은 폭의 표로 정렬합니다. 경력에는 담당업무 열을 포함하고, 날짜·학점·점수는 가운데 정렬합니다. 160자를 넘는 담당업무는 상세 페이지에 원문을 넣고 표에 참조를 표시합니다. 상세 페이지를 제외하면 경력 표 아래의 넓은 영역에 원문을 넣습니다. 모든 원문을 보존하며 행은 내용에 따라 늘어납니다. 긴 행은 페이지를 넘어갈 수 있고 표 헤더는 반복됩니다.
- 활용 역량·참고 자료·선택한 병역은 레이블과 값의 표로 정리합니다. 프로젝트·활동·연구·수상은 상세 페이지에 전체 내용과 실제 경험 구분을 유지합니다. 상세 페이지를 빼면 첫 페이지에 해당 경험의 이름과 기간을 남깁니다.
- 경험 상세와 자기소개서는 별도 페이지에서 시작합니다. 본문에 회사·부서·성명을 표시하며 바닥글에는 성명과 페이지 번호를 넣습니다. 자기소개서 문항과 답변은 저장한 순서와 문단을 유지합니다.
- 지원 구분은 생성 화면에서 선택한 신입·경력·인턴만 사용합니다. 경력 이력으로 추정하지 않으며 선택하지 않으면 빈칸입니다.

## 파일과 컴포넌트

- `freeform-application.docx`: 런타임에서 채우는 기준 파일입니다.
- `scripts/design-application-template.py SOURCE.docx OUTPUT.docx`: 기존 Findar DOCX의 작업 사본에서 공통 양식을 작성하는 디자인 도구입니다. **디자인 도구에만 python-docx가 필요**하며 묶음 문서 런타임으로 실행합니다. 입력 파일은 보존하고 다른 경로로 출력합니다.
- `scripts/generate-application-docx.py`: Python 3 표준 라이브러리만 사용합니다. 문단의 `findar_*` 북마크와 표의 `tblCaption`으로 컴포넌트를 찾아 채웁니다. 문단 순서에 따른 숫자 인덱스를 사용하지 않습니다.
- 출력은 문서 본문·머리글·바닥글·필드 갱신 설정만 바꾸고 스타일·테마·관계 등 나머지 패키지 부분은 그대로 보존합니다. 출력 문단의 템플릿 북마크는 제거해 중복 ID를 방지합니다.

## 검증

변경 시 빈 양식과 실제 입력본의 **모든 페이지**를 렌더링해 확인합니다. 장문 회사·부서와 장문 경력·자소서의 줄바꿈 및 페이지 이동도 확인합니다. 지원 회사·부서·구분의 본문 표시, 선택한 인적사항, 원문·패키지·A4 여백 보존, 고정 높이 부재, Word 파일 실제 생성은 회귀 테스트로 검사합니다.
