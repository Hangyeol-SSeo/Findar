# 자유양식 지원서 공통 템플릿 v2

처음 승인한 프로토타입을 바탕으로, 지원 회사와 팀·직무가 본문에서 명확하게 보이도록 가독성을 개선한 양식입니다. 실제 개인정보나 경력은 포함하지 않습니다.

## 시각적 우선순위

- 첫 페이지: 문서 종류 11pt, 지원 회사 22pt 굵게, 팀·직무 14pt 굵게, 지원자 이름 15pt, 연락처 10.5pt.
- 본문 11pt, 표 내용 10.5pt. 표의 행 간격과 섹션 간격을 구분하고, 한글 문서 격자에 의해 줄 높이가 과도하게 늘어나지 않게 설정합니다.
- 첫 페이지에는 학력·경력·자격을 먼저 배치합니다. 경험 상세를 포함하면 활동·연구·수상의 전체 내용은 상세 페이지에 모으고, 상세 페이지를 빼면 이력서에 해당 항목의 요약을 남깁니다.
- 선택한 병역·추가 인적사항은 하나의 구역으로 묶습니다. 상세·자기소개서 페이지에도 지원 회사·팀·지원자를 본문에 표시합니다.

## 템플릿과 생성기

- `freeform-application.docx`: 런타임에서 내용을 채우는 기준 파일입니다.
- `scripts/generate-application-docx.py`: Python 3 표준 라이브러리만 사용합니다. 본문 문단은 `findar_`로 시작하는 북마크, 표는 캡션으로 연결합니다. 문단 위치를 옮기거나 추가해도 고정된 숫자 인덱스에 의존하지 않습니다.
- `scripts/design-application-template.py SOURCE.docx OUTPUT.docx`: 최초 프로토타입에서 v2 양식을 만드는 디자인 도구입니다. 최초 원본은 커밋 `6acd510`의 템플릿에 보존되어 있습니다.
- 생성 시 기준 양식의 글꼴·테마·표·스타일을 유지하고, 내용·페이지 나눔·머리글·바닥글의 입력값을 바꿉니다.

변경 후에는 빈 양식과 실제 데이터가 채워진 문서를 모두 렌더링해 확인합니다. 회사·팀의 본문 표시와 글자 크기, 전체 내용 보존, 패키지 구성 보존은 회귀 테스트로 검사합니다.
