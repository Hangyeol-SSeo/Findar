# Findar 지원서 입력

Brave 또는 Chrome에서 한 번 설치한 뒤 사용합니다.

1. Findar의 지원 도우미에서 확장 기능 ZIP을 받아 압축을 풉니다.
2. Brave는 `brave://extensions`, Chrome은 `chrome://extensions`를 엽니다.
3. 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**로 이 폴더를 선택합니다.
4. Findar를 새로고침한 뒤 **웹 지원서 연결**을 누릅니다.
5. 열린 사이트에서 로그인하고 실제 지원서로 이동합니다.
6. 확장 기능 아이콘에서 **현재 양식 채우기**를 누릅니다. 결과를 검토하고 제출은 직접 합니다.

Findar 서버는 같은 컴퓨터의 `http://localhost:<포트>` 또는 `http://127.0.0.1:<포트>`에서 실행해야 합니다.
연결은 20분 후 만료됩니다. 서버 재시작 시 다시 연결해주세요.

입력칸의 라벨과 문맥만 Findar로 보내고 저장된 정보와 대응시킵니다. 생성된 값은 사용하지 않습니다.
이미 입력된 값, 로그인, 비밀번호, 동의, 서명, 주민번호, 계좌, 파일 첨부는 건드리지 않습니다.
제출 버튼이나 다음 단계 버튼을 누르지 않습니다. 사이트의 자동 저장은 입력 과정에서 발생할 수 있습니다.
iframe, 닫힌 shadow DOM, 사용자 정의 드롭다운은 지원하지 않습니다. 일반 input/textarea/select의 현재 단계만 처리합니다.
